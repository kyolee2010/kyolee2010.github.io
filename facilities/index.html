🔬 实验平台与设备

实验设施面向声学材料性能测试、复杂声场表征及噪声振动控制，包含声学材料测试、多模态噪声发射及表征、水下声场表征和弹性波声场表征四类平台，以及配套的通用声学设备。

1. 声学材料测试平台

集成传统、高声强、多模态和高温阻抗管系统，用于材料与结构的吸声、声阻抗和传声特性测试，覆盖不同声激励幅值、模态与温度条件下的声学性能表征。

1. 传统阻抗管系统

功能

  • 基于传递函数法，测量法向入射吸声系数、声阻抗及传声损失。
  • 不同截面管路覆盖互补频段，具体测量范围由管路尺寸与测试配置确定。

主要技术指标

  • 圆形截面：直径 29 mm（500–6400 Hz）、100 mm（50–1600 Hz）。
  • 方形截面：边长 25、30、50、70、100、180 mm。
  • 方形阻抗管系列综合覆盖频段：20–6400 Hz。
  • 测量配置：传声器阵列、数据采集系统及配套测量软件。

2. 高声强阻抗管系统

功能

  • 采用大幅值声激励，测试吸声材料与声衬的非线性声学响应。
  • 测量吸声特性及声阻抗随声压级的变化。

主要技术指标

  • 声压级范围：100–160 dB。
  • 工作频段：50–3200 Hz。

3. 多模态阻抗管系统

功能

  • 开展高阶声模态分解与模态转换测量。
  • 在相应模态可传播的频段内，表征材料与结构的多模态声学响应。

主要技术指标

  • 方形波导：25 mm × 25 mm（8 个传声器）、50 mm × 50 mm（32 个传声器）。
  • 测量频段：100–13000 Hz；各模态适用频段须满足传播截止条件。
  • 采集配置：多通道动态信号采集与配套模态分析软件。

4. 高温阻抗管系统

功能

  • 测量高温气体条件下材料与结构的吸声及声阻抗特性。
  • 通过控制测试温度，表征温度相关的声学响应。

主要技术指标

  • 系统组成：声源、加热装置、传声器阵列及水冷保护段。
  • 温控方式：管内气体加热。
  • 传声器保护方式：水冷段热防护。

2. 多模态噪声发射及表征系统

集成静态多模态声源、单级风扇及涵道风扇测试系统，用于无流与有流条件下的管道声场生成、模态分解和噪声传播测量，支持复杂声环境中的材料与结构性能评价。

1. 静态多模态声源系统

功能

  • 通过扬声器阵列独立幅相控制，在无流条件下生成可控的多模态声场。
  • 结合传声器阵列开展声模态分解，以及传播、转换、透射和反射测量。

主要技术指标

  • 声源阵列：32 个扬声器，支持独立幅相控制。
  • 工作频段：100–3500 Hz。
  • 测量配置：传声器阵列、多通道信号发生与采集设备。

2. 单级风扇测试系统

功能

  • 测量风扇运行条件下的管道噪声，分解主要周向声模态。
  • 通过声衬插入损失测量，评估风扇噪声衰减性能。

主要技术指标

  • 管道直径：600 mm。
  • 风扇转速范围：−3000 至 3000 rpm。
  • 声学测量频段：20–20000 Hz。
  • 主要周向模态分析频段：200–1600 Hz。

3. 涵道风扇测试系统

功能

  • 在有流条件下测量声学材料与声衬的传声损失。
  • 开展周向及径向声模态分解，分析管道模态传播与能量衰减。

主要技术指标

  • 管道直径：150 mm。
  • 风扇转速范围：11000–15000 rpm。
  • 工作频段：1000–5000 Hz。

3. 水下声场表征平台

集成水下声源、声压测量与二维扫描装置，用于水下声场空间分布及声传播特性的实验表征。

1. 水下声场扫描系统

功能

  • 生成水下声场，通过二维自动扫描测量声压幅值与相位分布。
  • 表征水下声场的透射、散射及辐射特性。

主要技术指标

  • 定位配置：二维移动平台与水槽。
  • 声学配置：浸没式换能器、针式水听器及抗碰撞水听器。
  • 信号链：信号发生、功率放大及数字化采集设备。

4. 弹性波声场表征平台

集成非接触式激光测振与压电加速度测量系统，用于固体结构的振动响应、空间振动分布及弹性波传播特性表征。

1. 扫描激光测振系统

功能

  • 非接触测量结构表面沿激光测量方向的振动速度分量。
  • 通过二维逐点扫描获得空间振动响应，用于结构模态与弹性波传播表征。

主要技术指标

  • 测振仪频率范围：0.5 Hz–22 kHz。
  • 二维扫描行程：约 1200 mm × 500 mm。
  • 系统配置：激光测振仪、移动平台、运动控制与同步采集设备。

2. 压电传感器阵列测试系统

功能

  • 测量单点或多测点的结构振动加速度响应。
  • 支持单轴与三轴测量，用于结构模态和弹性波传播实验。

主要技术指标

  • 单轴传感器：15 个；三轴传感器：7 个。
  • 单轴传感器频段：0.3 Hz–6 kHz 或 1 Hz–8 kHz，取决于所选传感器。
  • 三轴传感器频段：1 Hz–13 kHz。
  • 测量方向、量程与通道配置按传感器及采集设备确定。

5. 通用声学设备

配备用于声级、频谱、混响及多通道实验测量的通用仪器，作为各测试平台的配套测量设备。

1. 声学分析仪

功能

  • 开展声级、频谱与混响时间测量。
  • 用于声环境与室内声学参数表征。

主要技术指标

  • 频率计权：A、C、Z。
  • 频谱分析：倍频程、三分之一倍频程及 FFT。
  • 混响时间测量：63 Hz–8 kHz 倍频程频带。

2. 全向声源与功率放大器

功能

  • 为室内与建筑声学测试提供声激励。
  • 用于混响时间与空气声隔声等测量中的声源配置。

主要技术指标

  • 声源结构：十二面体配置，12 个扬声器。
  • 均衡声源频段：100 Hz–8 kHz。
  • 配套功放：D 类功率放大器，含粉红噪声发生功能。

3. 多通道采集与信号发生设备

功能

  • 完成声源信号输出、动态响应采集与数字化记录。
  • 结合配套软件开展实验控制、数据处理与分析。

主要技术指标

  • 硬件配置：模块化采集平台、动态信号采集模块与高速数字化设备。
  • 软件配置：实验控制、信号处理及多通道分析软件。
  • 采集通道数与频段按各测试系统配置确定。
